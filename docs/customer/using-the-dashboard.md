# Using the Dashboard

GuestKit is organized by navigation groups (sidebar, desktop nav, or CLI command groups). Use search / command palette when available.

## Surfaces

| Need | Surface |
|------|--------|
| Inspect | `guestkit inspect` |
| Doctor | `guestkit doctor` |
| Fix plans | fix-plans / repair |
| TUI | `guestctl` |

## Browse vs act

Inventory and status views are safe to explore. Mutating actions (deploy, migrate, sign, remediate) follow role gates and confirmation dialogs — review impact first.
